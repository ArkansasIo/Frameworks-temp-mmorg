# RPG MMORPG Framework

Full RPG/MMORPG framework target for Unreal Engine 5.7 with a Blueprint-first architecture, Unreal-facing C++ runtime, data-driven systems, and an optional portable C++23 domain layer.

## Status

This repository is being expanded from the framework specification into an implementation-oriented engine/framework. Unreal-facing code remains compatible with the engine toolchain; optional C++23 domain code is isolated from Unreal reflection/build requirements.

## Systems

- Attributes and derived statistics
- Modifier engine
- Resources
- Combat and damage
- Abilities and effects
- Buffs, debuffs and crowd control
- Items, equipment, inventory and loot
- Progression, XP, levels, classes and talents
- Enemy, boss, AI and threat systems
- PvE/PvP rules
- Quests, crafting, economy and factions
- Parties, guilds and social systems
- Persistence, replication and MMO service interfaces
- DataAssets, DataTables, schemas and Blueprint architecture
- UML, documentation and automated validation

See `Docs/` and `Framework/RPG_MMO_Framework_Template/` for the complete specification.
